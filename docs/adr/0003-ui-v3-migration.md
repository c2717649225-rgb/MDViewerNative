# ADR-0003：「安静的书桌」v3 界面的落地方式

- 状态：已采纳
- 日期：2026-09-29
- 相关：[ADR-0001](0001-architecture-evolution-principles.md)、[落地计划](../design/ui-v3-plan.md)、[设计规格](../design/quiet-desk-spec.md)

## 背景

v3 界面设计已由用户确认收官，要求原生程序尽可能与演示一致，同时守住 ADR-0001 的演进原则：不改外部契约、不破坏数据兼容、小步可回滚、不做大爆炸重写。

## 决定

1. **一个内部开关**：`config.txt` 隐藏键 `chrome=desk|classic`，默认 `classic`（U12 起默认 `desk`，没写即 desk；`chrome=classic` 切回），只在启动时读取。所有 v3 界面改动挂在这一个开关后面；开关关闭时行为和外观与现状一致。计划走完并经用户试用后单独切换默认值，再单独删除旧路径（登记技术债）。
2. **真值集中**：颜色只在 `ThemePalette`；尺寸只在新增的 `DeskMetrics`；命令文字与快捷键只在 `Commands.All`。
3. **每个新部件拆成几何（纯）/ 状态机（纯）/ 视图（宿主）三层**，前两层不引用 `Program`、`AppPreferences`、`RenderResources`，并登记进 `DependencyRulesTests` 名单。
4. **配置兼容**：新增 `paper=`，继续写 `theme=light|dark`；缺少 `paper=` 时由 `theme=` 推导。`toc=` 保留读写。
5. **快捷键只增不改**：目录保留 Ctrl+T，Ctrl+Shift+O 为新增别名；Ctrl+D 改为“当前浅色纸张 ↔ 灯下”；Ctrl+K 新增命令面板。
6. **起始页是界面标签而非文档会话**：不进 `DocumentTabs`，不写入 `tabs=`。
7. **动画统一走一个时钟**，遵守系统“减少动画”。
8. **不做**：竖排（用户定为不投入）、读屏（用户已否决）、导出与打印跟随纸张（另议）。

## 与规格的偏差

| 规格 | 落地 | 原因 |
|---|---|---|
| 目录 Ctrl+Shift+O | Ctrl+T 为主，Ctrl+Shift+O 为别名 | 外部契约 |
| 工具栏无「打开」「保存」 | 打开进 ⋯ 菜单和起始页；保存进编辑条；快捷键不变 | 按规格布局，功能不丢 |
| 未写标签放不下时怎么办 | 保留现有「+N」文档列表 | 规格空白处沿用现状 |
| 未写沉浸模式 | 保留 F11，隐藏标题栏里的工具，窗口按钮保留 | 已有功能不丢 |
| 返回提示 6 秒消失 | 改为绳上书签，直到返回或切换标签 | 规格如此，属有意行为变化 |
| 宽窗常驻目录侧栏 | 改为全屏卷目覆盖层 | 规格如此，属有意行为变化 |
| 页脚占位 | 页脚浮在正文上，视口不缩 | 规格如此 |
| 默认字号 16 | desk 界面默认 17；`font=16` 视为“没改过”迁移为 17，其他值不变 | 旧版每次保存都写 `font=16`，无法区分用户是否改过（U3） |
| H2 方印 | 标题自带编号（“1.”“第二章”“三、”“(一)”“IV.”）时不加方印 | 两套编号并列反而难读（U3） |
| 链接：墨色文字、朱色下划线 | 朱色文字、同色下划线（悬停时演示本来就变朱色） | DirectWrite 下划线跟随文字颜色，分色需自绘文字渲染器，得不偿失（U3b） |
| 强调：着重点（text-emphasis） | 保持斜体/粗体 | DirectWrite 无着重点，自绘成本高（U3b） |
| 编辑态页脚（第 n 行 · Markdown · UTF-8） | 推迟到 U9a 与编辑条一起做 | 编辑态布局 U9 才重做，先做会返工（U4） |
| 书签绳：只有按住绳子才能拖 | 整列按下都可拖（相对拖动），不动松开算点击 | 用户要求“任何地方都能拖”；绳子只有 11 宽，整列更好抓（U5a） |
| 书签绳：点击列内总跳转 | 点击处离当前位置不足 12 不跳 | 与演示绳子点击同值，避免手抖误留返回书签（U5a） |
| 当前章节判定 | 统一用演示口径：标题进入视口上方 94 内即为当前章节，刻度位置 70、刻度跳转 60，集中在 DeskMetrics | U4 先用了 24，与刻度“绳到即读”不一致（U5b） |
| 返回书签（U5c） | desk 下不画正文底部的返回标签；书签不计时，返回、切换标签、切换模式时清除；跨文档跳转不留书签；页内跳转一律平滑滚动；动画统一由 `DeskAnimations`（计时器 17）驱动；查找跳转留书签随 U7 | 书签只标记“同一篇里刚才读到哪”，跨文档由 Alt+← 历史负责 |
| 编辑时的「保存」 | U9a 编辑条落地前，desk 顶栏在编辑态临时显示只写字的「保存」 | 保存不能只剩快捷键（U6a） |
| 「打开」入口 | 标签后的「+」、⋯ 菜单顶部、Ctrl+O；起始页随 U10 | 演示 .tab-add（U6a） |
| 外观面板 | U11 之前先用原生菜单：纸张五选一、衬线、字号 | 纸张此前没有菜单入口，只能 Ctrl+D（U6a） |
| 提示框圆角 6、透明度 0.94 | Win11 系统小圆角（4），不透明；键帽字号 10（演示 9.1） | 分层窗口与系统圆角不可兼得；Windows 9 px 小字发虚（U6a2） |
| 最大化按钮的提示 | 不给（最小化、关闭有） | Win11 在最大化按钮上弹贴靠布局，两者会叠（U6b） |
| Win10 顶边 1px 边框 | 不画 | DWM 在 Win10 不画自定义框架的顶边，接受（U6b） |
| 单文档也显示标签 | desk 下总显示标签；classic 不变 | 演示中标签就是文档名（U6a） |
| 打印不跟随纸张 | 打印仍用 v2.2 配色，但版式（行高、标题字体、留白）跟随 desk | 版式是阅读器的，颜色是屏幕的；同一 DocView 排版，避免两套排版分叉（U3） |

## 后果

- 两套界面并存期间有维护成本；由 U12、U13 的明确触发条件控制期限。
- 自绘标题栏是最大风险，单独成步、单独回滚，并由用户实机验收。
- 依赖方向检查新增 DeskPure 集合（ThemePalette、DeskMetrics、Appearance、PaperTexture、ReadingStyle、FooterModel、CordGeometry、DeskAnimations、DeskToolbarLayout、DeskTip、DeskFrame、TitlebarQuiet、InkCircle、SelectionBubble、Juan、EditBar、LetterPaper、InkDrop、Home、CommandSearch、AppearancePanel），不得引用上层（U4、U5a）。
- desk 下窗口不带 `WS_VSCROLL`，所有 `SetScrollInfo` 调用都经 desk 判断跳过（它会把滚动条自动显示出来）；排版宽度不再预留滚动条宽（U5a）。
- 信笺不替换 RichEdit：在它画完之后用 GDI 叠画格线、页边与镇尺，并在它直接重画文字的消息之后补画（U9b）。若日后出现闪烁，按计划降级为只画镇尺，只需收窄 `EditorControl.Letter` 的绘制内容。
