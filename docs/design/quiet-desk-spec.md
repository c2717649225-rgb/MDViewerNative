# 安静的书桌 · 界面设计规格（v3 定稿）

> 本文件从演示 `quiet-desk-ui-v3.html` 中提炼，是原生实现（Win32 + DirectWrite / D2D）的依据。
> 演示代码是多轮迭代叠出来的，**以本规格为准，不要照抄演示代码**。
> 单位：设备无关像素（DIP）。时长单位：毫秒。
> 原生落地时与本规格的偏差见 `docs/adr/0003-ui-v3-migration.md`。

---

## 0. 原则

1. **阅读为先**：正文永远是画面主体；其他东西在你读的时候退后。
2. **形用古意，词用白话**：样子可以有书卷气，文字、位置、操作必须一看就懂。
3. **位置遵循 Windows 惯例**：标签在上、滚动在右、窗口按钮在右上、状态在页脚。
4. **不教学**：不做引导卡、不做教程。能点的东西看上去就能点；提示只说「做什么 + 快捷键」。
5. **隐喻必须过三关**才能用：位置和用法跟已有习惯一致；比普通做法多提供信息；不新增控件。
6. **频繁操作要安静**：保存、滚动、切换这类操作不弹提示、不做夸张动画。

## 1. 颜色（纸张）

| 纸张 | desk 桌面 | paper 纸面 | ink 正文 | ink-2 次要 | muted 辅助 | faint 装饰 | rule 分隔 | accent 朱 |
|---|---|---|---|---|---|---|---|---|
| 宣纸 | `#ebe4d6` | `#f6f1e7` | `#2a2521` | `#544c43` | `#6c6358` | `#b3a894` | `#e2d8c6` | `#b0361f` |
| 青瓷 | `#bfd0bb` | `#cddcc9` | `#1b2a23` | `#34463d` | `#44554c` | `#8fa592` | `#b8cab4` | `#8f2f1d` |
| 素白 | `#f0f0ef` | `#ffffff` | `#141414` | `#3d3d3d` | `#666666` | `#b0b0b0` | `#e6e6e6` | `#b0301a` |
| 灯下 | `#141311` | `#1c1a18` | `#e6dccb` | `#bdb2a1` | `#9a8f80` | `#5a534b` | `#2f2c28` | `#e0805f` |

- **默认「跟随系统」**：Windows 浅色 → 宣纸，深色 → 灯下；系统切换时实时跟随。
- **高对比度**：系统开启时全部改用系统色（`COLOR_WINDOW`、`COLOR_WINDOWTEXT`、`COLOR_HIGHLIGHT` 等），不画纸纹、不画阴影；书签绳、查找当前项、朱笔圈用 Highlight 色。
- **对比度红线**（相对 paper，桌面上的文字相对 desk）：
  - ink ≥ 10:1；ink-2 ≥ 6:1；muted ≥ 4.5:1（在 desk 上也 ≥ 4.5:1）；accent ≥ 4.5:1。
  - faint **只用于装饰线**（刻度、分隔），不承载文字。
  - 选中状态的工具按钮文字 = accent 与 ink 按 85:15 混合（保证在淡朱底上 ≥ 4.5:1）。
### 1.1 次级颜色（U1 补全）

| 纸张 | 代码底 paper-2 | 关键字 | 类型 | 字符串 | 数字 | 注释 | 控件边框 |
|---|---|---|---|---|---|---|---|
| 宣纸 | `#ede6d8` | `#a3402c` | `#3f5f7a` | `#556e35` | `#8e5b25` | `#6b6458` | `#918778` |
| 青瓷 | `#c2d3be` | `#953928` | `#244f63` | `#36603b` | `#754e1b` | `#4b5a52` | `#677c6b` |
| 素白 | `#f4f4f2` | `#a3321f` | `#1f4f7a` | `#3d6b1f` | `#935a14` | `#6e6e6e` | `#8c8c8c` |
| 灯下 | `#252320` | `#e8957a` | `#98b8cf` | `#aec78c` | `#ddae70` | `#918b80` | `#7a7166` |

- 代码色在代码底上 ≥ 4.5:1；控件边框在纸面上 ≥ 3:1。部分颜色较最初演示加深，演示已同步。
- 半透明色在原生端预先与纸面合成为不透明色：选区 = 朱 16%（青瓷为墨绿 20%，灯下 26%）；查找命中 = wash；`==高亮==` = wash 加深约 1.4 倍；提示块底 = 朱 7%–10%。
- 引用：左线 rule-2，文字 ink-2，宋体 1.08em。表头：ink-2，上 1.5 / 下 1 线。链接：文字同正文，下划线 accent。
- 对话框、图片窗口、源码编辑区、查找条跟随当前纸张（纸面、正文、边框三色）；系统菜单保持系统样式。
- 权威数值在 `engine/ThemePalette.cs` 的 `PaperPalette`，本表与之一致。

- 纸纹：宣纸 7% 强度噪点；青瓷 0.8 倍；灯下 0.45 倍；素白无。灯下另加顶部暖光与极弱暗角。
- 切换纸张：从点击处圆形晕开 900 ms；系统开启「减少动画」时直接切换。

## 3. 顶栏（44 高）

从左到右：**印章「阅」**（命令面板，Ctrl+K）→ **标签** → 空白拖动区 → **工具** → 窗口按钮。

### 标签
- 高 36，最大宽 220，完整显示文件名（过长省略）。
- 当前标签与纸面同色、连成一片，顶端 2 高朱线，底部两侧有内凹圆角过渡。
- 关闭按钮在右；**未保存时显示为墨点**（见 §8.1），悬停墨点变回 ×。
- 起始页标签只有房子图标 +「起始页」；窗口宽 < 1180 时只剩图标。

### 工具（图标 + 两个字）
`查找` `目录` `[阅读|编辑]` `外观` `⋯`
- 宽 < 1180：只显示图标。
- 起始页上「查找」「目录」「阅读/编辑」禁用（35% 透明）。
- 「⋯」菜单：打开文件、重新打开关闭的标签、竖排阅读、导出 HTML、打印、命令面板。
- 每个按钮悬停 380 ms 后显示提示：**做什么 + 快捷键**，不写长句。

### 退后一步
- 阅读模式下**往下滚动**超过 120 后，工具、非当前标签、窗口按钮的文字转为 muted（600 ms 渐变）；分段按钮的选中底色淡出。
- **往上滚 30 以上、回到顶部、鼠标进入顶栏、键盘焦点进入顶栏、切换标签或模式**时立即恢复。
- 退后后仍满足对比度 ≥ 4.5:1；不隐藏任何东西。

## 4. 书签绳（取代滚动条）

右侧 24 宽的一列，从上到下：顶部 36 起，底部留 60（页脚 34 + 余量）。

### 组成
| 部件 | 位置 / 尺寸 | 说明 |
|---|---|---|
| 绳子 | 距右 5，宽 11，长 = 36 + 进度 × 可用高度 | 朱色，带细微横向明暗；末端燕尾缺口 9 |
| 刻度 | 与绳子同一中轴，宽 13（三级标题 7），高 1.5 | **没有轨道线**，只画刻度 |
| 已读刻度 | 同上 | 在绳子上显示为 paper 色 80% 的浅刻痕 |
| 未读刻度 | 同上 | faint 色短线 |
| 返回书签 | 距右 12，24×16，左尖右平 | 塞在绳子后面、从左侧探出 |

- 可点击区域覆盖整列，但**看得见的只有绳子和刻度**。
- 悬停、拖动时**尺寸不变**（仅亮度 +8%）。

### 交互
| 操作 | 结果 |
|---|---|
| 按住绳子**任何位置**拖动 | 相对拖动：手移多少，绳子走多少（与滚动条滑块一致） |
| 按下后移动 < 4 就松开 | 视为**点击** |
| 点击列内任意位置（含绳子上） | 跳到该位置，留下返回书签 |
| 点击处 ±7 内有刻度 | 跳到该章节，留下返回书签 |
| 鼠标靠近刻度 ±7 | 刻度横向放大 1.35 倍并变亮，提示显示**章节名** |
| 悬停绳子（不靠近刻度） | 提示「已读 55%」 |
| 点击返回书签 / Alt+← | 平滑滚回，书签消失 |

- 返回书签出现时：弹入动画 600 ms；页脚显示「Alt+← 返回」3 秒。
- 以下操作会留下返回书签：目录跳转、刻度跳转、列内点击、站内链接、查找跳转。**滚轮、键盘翻页、拖动不留**。
- 切换标签、切换模式时清除返回书签。
- 跳转一律平滑滚动（系统「减少动画」时直接跳）。

## 5. 页脚（34 高，兼任状态栏）

- 顶部 26 高渐变，从透明过渡到纸色，正文从底下滑过。
- **左**：鱼尾标记 + 当前章节（如「叁 · 朱笔圈点」）；开篇显示「开篇」。
  - 鼠标停在**外部链接**上：显示 ↗ + 完整网址（过长省略）。
  - 停在**站内链接**上：显示 → + 目标章节。
  - 编辑模式：显示「第 n 行」。
- **右**：临时状态（朱色）· 字数 · 已读 n%（不显示阅读时长）；缩放不是 100% 时追加缩放比例。编辑模式显示「Markdown · UTF-8」。

---

## 6. 查找

- Ctrl+F 或「查找」：右上角浮出查找框（输入框 · 计数 n/m · 上一处 · 下一处 · 关闭）。
- 所有匹配铺淡朱底（wash）；**当前一处**再用手绘朱笔圈圈出（路径描绘动画 500 ms），每次切换先清掉旧圈。
- Enter 下一处，Shift+Enter 上一处，Esc 关闭。
- 选中文字后浮出气泡「复制 / 查找」。

---

## 7. 目录

- Ctrl+T（别名 Ctrl+Shift+O）或「目录」：全屏卷目，半透明纸色背景 + 模糊。
- 右上角「关闭 Esc」按钮；点空白处也关闭。
- 条目：章节号 · 标题 · 点线引导 · 位置百分比；当前章节朱色并标「当前」。
- 打开时焦点落在当前章节；↑↓ / Home / End 移动，Enter 跳转。

---

## 8. 编辑

- Ctrl+E 或分段按钮切换；正文变为信笺：每行下方一道淡朱格线，左侧双线页边，行号用 muted。
- **顶部编辑条**（44 高，吸顶不随滚动离开）：
  - 左：✎ 编辑中 · 状态（「○ 已保存」/「● 有改动未保存 · 草稿已自动备份」）。
  - 右：「保存 Ctrl+S」（有改动时朱色实心，无改动时置灰）·「完成 Ctrl+E」。
- **镇尺**：光标所在行下方的格线变为 1.5 高朱线（80% 不透明），随光标移动，出现动画 250 ms。

### 8.1 墨未干（未保存标记）
- 标签上的未保存标记是一滴墨：8 直径，朱色，左上角极小的湿润高光，外圈 1.5 淡晕。
- 第一次产生改动：墨滴从 0 放大到 1.25 再回到 1（450 ms）。
- 保存：先失去光泽、收到 0.9（前 35%），再收到 0.55 并淡出（共 1200 ms），然后恢复为普通 ×。

## 9. 起始页

- 左栏：「继续阅读」大卡片（标题、读到哪一章、进度条、已读百分比、主按钮）；最近 6 个文件卡片（文件名、摘要、目录、时间，轻微随机旋转 ±1°）；「打开文件…」按钮 + 可拖入提示。
- 右栏：竖排问候语 + 日期 +「书桌」印章；窗口宽 < 820 时隐藏。
- 继续阅读卡片的进度和章节来自**真实的上次阅读位置**。

## 10. 外观面板

- 纸张五项（跟随系统 / 宣纸 / 青瓷 / 素白 / 灯下），每项一行场景说明。
- 底部说明：「Windows 开启高对比度时，会自动改用系统配色。」
- 正文字体：黑体 / 宋体。字号：− 100% ＋。

| 快捷键 | 作用 |
|---|---|
| Ctrl+K / Ctrl+Shift+P | 命令面板 |
| Ctrl+F | 查找 |
| Ctrl+T（别名 Ctrl+Shift+O） | 目录 |
| Ctrl+E | 阅读 / 编辑 |
| Ctrl+S | 保存 |
| Ctrl+O | 打开文件 |
| Ctrl+W | 关闭标签 |

| Ctrl+Tab / Ctrl+Shift+Tab | 切换标签 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 放大 / 缩小 / 还原 |
| Ctrl+D | 当前浅色纸张 ↔ 灯下 |
| F11 | 沉浸（隐藏标题栏里的工具） |

- 焦点框：1.5 宽，accent 75%，外扩 1；高对比度下 2 宽 Highlight。

## 12. 竖排（次要功能）

- 只在「⋯」菜单和命令面板中提供。
- 正文从右到左竖排，滚轮自动变为左右翻；书签绳横在页脚上方，从右往左走，刻度同轴。
- 不再投入额外打磨。

---

## 13. 明确不做

- 教程、引导卡、首次使用提示。
- 拉灯绳切换夜间、保存时盖章、翻页动画、卷轴展开。
- 起始页卡片上的「书口」书签（测试中没人看得懂）。
- 纸边书口厚度表示进度（与书签绳重复）。
- 任何让书签绳在悬停或拖动时变粗的效果。
- 阅读时长 / 剩余时间（「约 n 分钟」）：信息价值低，已从页脚、文首、起始页全部移除。

## 14. 字体与图标（U1 补全）

| 用途 | 首选 | 退路 |
|---|---|---|
| 界面、黑体正文 | Segoe UI Variable Text + Microsoft YaHei UI | Segoe UI + 微软雅黑 |

| 代码 | Cascadia Mono | Consolas |

图标码位（两套字体相同）：查找 E721、目录 E8FD、阅读 E736、编辑 E70F、外观 E793、更多 E712、起始页 E80F、关闭 E8BB、新建 E710、最小化 E921、最大化 E922、还原 E923。演示中的 SVG 图标为近似示意，原生以图标字体为准。印章「阅」用宋体粗体绘制在朱色圆角方块上，不依赖图标字体。

## 15. 原生实现要点

| 部件 | 实现 |
|---|---|
| 竖排 | DirectWrite `DWRITE_READING_DIRECTION_TOP_TO_BOTTOM` + `FLOW_DIRECTION_RIGHT_TO_LEFT` |
| 纸张晕开 | D2D 圆形几何作裁剪层，旧帧与新帧合成 |
| 朱笔圈 | D2D 路径几何 + 描边长度动画 |
| 书签绳 | 自绘控件：命中测试整列；拖动用相对位移；点击/拖动以 4 像素阈值区分 |
| 刻度命中 | 按距离（±7）判断，不依赖刻度本身的命中区域 |
| 墨点 / 镇尺 | 简单 D2D 图元 + 定时动画；遵守系统「减少动画」 |
| 高对比度 | 监听 `WM_SETTINGCHANGE` / `SPI_GETHIGHCONTRAST`，切到系统色表 |
| 退后一步 | 由滚动方向驱动的顶栏颜色插值；不隐藏、不改变布局 |
