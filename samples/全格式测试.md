# CommonMark 补全(PLAN-F 批次)

## 实体解码
命名与数字实体应解码:版权 &copy; 、商标 &trade;、注册 &reg;、省略号 &hellip;、破折号 &mdash;、小于号 &lt;、大于号 &gt;、数字写法 &#169; 与 &#xA9; 应同为 ©。

代码 span 内必须保持字面:`&copy; &#169; &amp;`。

反斜杠转义不解码:\&copy; 应显示为字面 &copy;。

未知实体按字面保留:&nosuch; 与 &fake; 不应变。

## 链接标题
括号 URL 加标题:[平衡括号链接](https://example.com/a_(b) "标题文字") 应只显示链接文字,URL 含括号不断链。

引用式链接(标题在下一行):

[r1][ref1]

[ref1]: https://example.com/ref
    "这是下一行的标题"

上面应渲染出链接 [r1][ref1] 指向 https://example.com/ref,且 "这是下一行的标题" 不得作为正文出现。

## 四空格缩进代码块
段落之后隔空行的缩进块应成为代码块:

    SELECT * FROM users
    WHERE active = 1

引用内缩进代码:

> 引用段落
>
>     quoted = code_inside_quote

列表项后的缩进行是续行,不是代码块:

- 列表项甲
    这一行的四个空格缩进属于列表项续行

段落紧跟的缩进行是懒续行,合并进同一段:
这是上一行,
    这一行有缩进但应并入上面段落。

## 松散与紧凑列表
紧凑列表(无空行)项间距紧:

- 紧凑甲
- 紧凑乙
- 紧凑丙

松散列表(项间空行)项间距应明显更大:

- 松散甲

- 松散乙

- 松散丙

## 内联 HTML 白名单
下划线:<u>下划线文字</u>。加粗:<b>HTML粗体</b> 与 <strong>strong粗体</strong>。高亮:<mark>荧光标记</mark>。

上下标:H<sub>2</sub>O、x<sup>2</sup>。键盘键:<kbd>Ctrl</kbd> + <kbd>C</kbd>。

删除:<del>删除线</del>、<s>同样是删除线</s>。

链接:<a href="https://example.com/html">HTML 锚点链接</a> 应可点击。

透传标签只剥外壳:<span>span 内容正常显示</span>。

未知标签按字面显示:<div>这个 div 标签应原样可见</div>。

## 强调边界用例
三重定界:***粗斜体*** 应同时粗与斜。

词内下划线不触发:snake_case_word 与 file_name_ext 保持字面。

空格隔开的星号不触发:a * b * c 保持原样。

嵌套:**外层 *内层* 继续** 内层应粗斜并存。

未配对孤星不吞字:5 * 3 = 15 和 ** 未配对原样显示。
